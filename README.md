# 🎬 Lampa VLC Playlist

Плагин для **[Lampa](https://lampa.mx)**, который запускает сериалы из **TorrServer** во внешнем плеере (VLC, mpv) **с автоматическим переходом на следующую серию**.

> Встроенный плеер Lampa на ПК часто воспроизводит видео **без звука**: браузерный движок не умеет AC3, E-AC3 и DTS. VLC и mpv играют любой звук, а плагин передаёт им весь сезон плейлистом.

## ✨ Возможности

- ▶️ Плейлист **с выбранной серии** до конца сезона
- 🔢 Правильный порядок серий: `E2` идёт перед `E10`
- 🔊 Любой звук: AC3, E-AC3, DTS, многоголосые озвучки
- 🪟 Два способа запуска: скачать `.m3u` или открыть плеер сразу ссылкой `vlcpl://`
- ⚙️ Настройки прямо в Lampa
- 🤖 На Android не мешает штатному внешнему плееру

## 🚀 Быстрый старт

1. В Lampa откройте **Настройки → Расширения → Добавить плагин**
2. Вставьте ссылку:
   ```
   https://cdn.jsdelivr.net/gh/Bikdin/lampa-plugins/lampa-vlc-playlist.js
   ```
3. Перезапустите Lampa
4. Запустите серию из торрента и выберите **«Внешний плеер (VLC) — с автопереходом»**

## 📥 Способы запуска плеера

### Способ 1. Файл `.m3u` (по умолчанию)

Браузер скачивает плейлист, VLC его открывает. Чтобы VLC открывался сам:

1. В настройках браузера выключите **«Всегда спрашивать, куда сохранять файлы»**:
   - Chrome: `chrome://settings/downloads`
   - Edge: `edge://settings/downloads`
   - Яндекс: `browser://settings/downloads`
2. После первого скачивания нажмите у файла в панели загрузок **«Всегда открывать файлы этого типа»**

### Способ 2. Ссылка `vlcpl://`: без скачивания (Windows)

1. Скачайте [`install-lampa-vlc.cmd`](install-lampa-vlc.cmd) и запустите его. Права администратора не нужны.
2. В Lampa выберите **Настройки → VLC плейлист → Способ открытия → «Ссылка vlcpl://»**
3. При первом запуске браузер спросит, можно ли открыть приложение. Отметьте **«Всегда разрешать»**.

<details>
<summary><b>TorrServer не в домашней сети</b></summary>

Из соображений безопасности обработчик по умолчанию принимает только локальные адреса (`localhost`, `192.168.x.x` и т.п.). Чтобы разрешить удалённый сервер, выполните в PowerShell:

```powershell
Add-Content "$env:LOCALAPPDATA\LampaVLC\allowed-hosts.txt" "ts.example.com"
```

Добавляйте только серверы, которым доверяете.
</details>

<details>
<summary><b>Использовать mpv вместо VLC</b></summary>

```powershell
winget install mpv.net
setx LAMPA_VLC_EXE "C:\Program Files\mpv.net\mpvnet.exe"
```

После этого полностью перезапустите Lampa. Вернуть VLC:

```powershell
[Environment]::SetEnvironmentVariable('LAMPA_VLC_EXE', $null, 'User')
```
</details>

<details>
<summary><b>Удаление обработчика</b></summary>

```bat
reg delete HKCU\Software\Classes\vlcpl /f
rmdir /s /q "%LOCALAPPDATA%\LampaVLC"
```
</details>

## ⚙️ Настройки

**Настройки → VLC плейлист**

| Параметр | Описание |
|---|---|
| **Включить** | Включает и выключает плагин |
| **Режим** | «Спрашивать» показывает меню при каждом запуске, «Сразу во внешний плеер» открывает без меню |
| **Способ открытия** | `.m3u` или `vlcpl://` |
| **Путь к плееру** | Для десктопной Lampa, если она разрешает запуск программ, например `C:\Program Files\VideoLAN\VLC\vlc.exe` |
| **Не работать на Android** | По умолчанию включено |

## 📱 Android

Плагин на Android не нужен. Установите **[Just Player](https://play.google.com/store/apps/details?id=com.brouken.player)** и выберите его в **Настройки → Плеер → Тип плеера → Внешний**. Lampa сама передаст список серий.

## 🛠 Решение проблем

| Проблема | Решение |
|---|---|
| Нет раздела «VLC плейлист» | Полностью перезапустите Lampa. Если не помогло, удалите плагин и добавьте заново |
| После обновления работает старая версия | Откройте [purge-ссылку jsDelivr](https://purge.jsdelivr.net/gh/Bikdin/lampa-plugins/lampa-vlc-playlist.js) и перезапустите Lampa |
| Окно *«TorrServer is not in the local network»* | Добавьте сервер в `allowed-hosts.txt` (см. выше) |
| Серия долго грузится | В VLC: **Инструменты → Настройки → Все → Ввод/кодеки → Кэш сети** = 3000–5000 мс |
| Что-то другое | Нажмите `F12`, откройте вкладку Console и пришлите строки с `[vlc-pl]` в [Issues](../../issues) |

## 🔧 Как это работает

1. Плагин перехватывает запуск торрента в Lampa
2. Берёт список серий из плейлиста Lampa или напрямую у TorrServer (`/stream?link=…&stat`)
3. Собирает плейлист `.m3u` с выбранной серии
4. Отдаёт его плееру: скачиванием файла или через обработчик ссылки `vlcpl://`
