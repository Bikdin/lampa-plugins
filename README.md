VLC плейлист для Lampa
Плагин для Lampa, который отправляет сериал из TorrServer во внешний плеер (VLC, mpv) плейлистом: начиная с выбранной серии и дальше по порядку. Плеер сам включает следующую серию.

Нужен, если встроенный плеер Lampa на ПК не играет звук (AC3, E-AC3, DTS) или не устраивает чем-то ещё.

Установка
В Lampa: Настройки → Расширения → Добавить плагин
Вставьте ссылку:
https://cdn.jsdelivr.net/gh/Bikdin/lampa-plugins/lampa-vlc-playlist.js
Перезапустите Lampa.
Как пользоваться
Запустите серию из торрента и выберите «Внешний плеер (VLC) — с автопереходом».

Плагин отдаёт плейлист одним из двух способов. Он выбирается в настройке «Способ открытия».

Способ 1. Скачать .m3u (по умолчанию)
Браузер скачивает плейлист .m3u, его нужно открыть в VLC. Чтобы VLC открывался сам:

В настройках браузера выключите «Всегда спрашивать, куда сохранять файлы».
После первого скачивания нажмите в панели загрузок «Всегда открывать файлы этого типа».
Способ 2. Ссылка vlcpl:// (без скачивания, только Windows)
Скачайте и запустите install-lampa-vlc.cmd. Права администратора не нужны.
Если TorrServer не в домашней сети (адрес вида ts.example.com), разрешите его:
Add-Content "$env:LOCALAPPDATA\LampaVLC\allowed-hosts.txt" "ts.example.com"
В Lampa: Настройки → VLC плейлист → Способ открытия → «Ссылка vlcpl://».
При первом запуске браузер спросит, можно ли открыть приложение. Отметьте «Всегда разрешать».
Чтобы вместо VLC открывался mpv / mpv.net, выполните команду и перезапустите Lampa:

setx LAMPA_VLC_EXE "C:\Program Files\mpv.net\mpvnet.exe"
Удалить: reg delete HKCU\Software\Classes\vlcpl /f

Настройки
Настройки → VLC плейлист

Параметр	Что делает
Включить	Включает и выключает плагин
Режим	«Спрашивать» показывает меню при каждом запуске, «Сразу во внешний плеер» открывает без меню
Способ открытия	Скачать .m3u или ссылка vlcpl://
Путь к плееру	Только для десктопной Lampa, если она разрешает запуск программ, например C:\Program Files\VideoLAN\VLC\vlc.exe
Не работать на Android	По умолчанию включено. На Android лучше штатный внешний плеер Lampa
Android
Плагин на Android не нужен. Установите Just Player и выберите его в Настройки → Плеер → Тип плеера → Внешний. Lampa сама передаст список серий.

Если не работает
Нет раздела «VLC плейлист» в настройках. Перезапустите Lampa полностью. Если раздел так и не появился, удалите плагин и добавьте заново.
После обновления плагина работает старая версия. Откройте https://purge.jsdelivr.net/gh/Bikdin/lampa-plugins/lampa-vlc-playlist.js и перезапустите Lampa.
Окно «TorrServer is not in the local network». Добавьте адрес сервера в allowed-hosts.txt (см. способ 2).
Серия долго грузится в VLC. В VLC откройте Инструменты → Настройки → Все → Ввод/кодеки и поставьте «Кэш сети» 3000–5000 мс.
Ошибки в консоли. Нажмите F12, откройте вкладку Console и найдите строки с [vlc-pl].
